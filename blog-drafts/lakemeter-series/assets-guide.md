## Recommended App Screenshots to Capture Manually

The deployed app requires Databricks SSO, so capture these manually from a logged-in browser session:

1. **Calculator overview**
   - Create a demo estimate named `Customer Data Platform Estimate`.
   - Use public/synthetic data only.
   - Add 2-3 workloads such as Jobs, DBSQL, and Lakebase.
   - Capture the calculator page with the cost summary visible.
   - Suggested filename: `assets/lakemeter-calculator-page.png`.

2. **Expanded cost breakdown**
   - Expand one workload.
   - Show the DBU formula and cost details.
   - Avoid showing internal workspace URLs, emails, or customer names.
   - Suggested filename: `assets/lakemeter-cost-breakdown.png`.

3. **Excel export**
   - Export the demo estimate.
   - Open the Excel file and capture the summary/workload table.
   - Suggested filename: `assets/lakemeter-excel-export.png`.

4. **Short walkthrough video**
   - Keep it to 15-30 seconds.
   - Show: create estimate -> add workload -> cost updates -> export.
   - Export as MP4 for LinkedIn.
   - Suggested filename: `assets/lakemeter-walkthrough.mp4`.

## Screenshot Rules

- Do not show customer names.
- Do not show internal workspace URLs.
- Do not show emails, tokens, account IDs, or private data.
- Prefer synthetic names:
  - `Customer Data Platform Estimate`
  - `ETL Pipeline`
  - `Analytics Warehouse`
  - `Lakebase App Backend`
