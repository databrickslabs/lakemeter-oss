WHAT IS LAKEMETER?

Lakemeter is a Databricks sizing calculator with AI-copilot that helps solution architects estimate Databricks costs. Inspired by AWS, Azure, and GCP calculators, it enables you to create detailed cost estimates with multiple workload line items.

Time Required: 30-40 minutes
Testing Focus: Create estimates, add workloads, use AI copilot, save & export

TESTING INSTRUCTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: CREATE YOUR FIRST ESTIMATE (5 minutes)

1. Access Lakemeter: [URL to be provided]
2. Click "New Estimate" or "Create Estimate"
3. Fill in estimate details:
   - Estimate Name (e.g., "Customer Name - Production Workloads")
   - Select Cloud: AWS, Azure, or GCP
   - Select Region from dropdown
   - Select Tier: Standard, Premium, or Enterprise
4. Optional: Tag with Salesforce
   - Account
   - Opportunity  
   - Use Case

Test Checkpoint:
□ Can you create a new estimate successfully?


STEP 2: ADD LINE ITEMS MANUALLY (10 minutes)

Add at least 3 different workload types manually.

Example Line Item 1: JOBS CLASSIC
• Workload Type: JOBS Classic
• Driver Instance: m5.xlarge
• Worker Instance: m5.xlarge
• Number of Workers: 10
• Photon Enabled: Yes
• Driver Pricing: On-demand
• Worker Pricing: Spot
• Usage: 8 runs/day, 60 min/run, 22 days/month

Example Line Item 2: DBSQL SERVERLESS
• Workload Type: DBSQL Serverless
• Warehouse Size: Medium
• Number of Clusters: 1
• Usage: 730 hours/month

Example Line Item 3: MODEL SERVING
• Workload Type: Model Serving
• GPU Type: gpu_small_t4
• Usage: 730 hours/month

Test Checkpoints:
□ Can you add multiple line items?
□ Do costs calculate correctly for each line?
□ Can you see total estimate cost?
□ Can you edit line items after adding?
□ Can you delete line items?


STEP 3: USE AI COPILOT (10 minutes)

Test the AI Copilot feature to get configuration suggestions.

IMPORTANT: AI Copilot provides suggestions only. You must manually select and apply the recommended configurations in the frontend.

Workflow:
1. Enter workload description in AI Copilot
2. Review AI's configuration suggestions
3. Manually select/apply suggested values in the frontend form
4. Add line item to estimate

Try these prompts:

1. "Add a nightly ETL job that processes 500GB of data, runs for 2 hours"
   - Review AI suggestions (workload type, instance types, etc.)
   - Manually select suggested configurations
   - Add to estimate

2. "Add 50 business analysts querying data 8 hours per day"
   - Review AI suggestions
   - Manually apply to frontend
   - Add to estimate

3. "Add a streaming workload processing Kafka data 24/7"
   - Review AI suggestions
   - Manually configure based on suggestions
   - Add to estimate

Test Checkpoints:
□ Does AI understand the workload description?
□ Does AI recommend appropriate workload type?
□ Does AI suggest reasonable instance types and configurations?
□ Are suggestions clear and actionable?
□ Can you easily transfer suggestions to the frontend form?
□ Can you edit AI suggestions before applying?
□ After manual application, are costs calculated correctly?


STEP 4: SAVE & EXPORT (5 minutes)

SAVE ESTIMATE
1. Click "Save" or "Save Estimate"
2. Verify estimate is saved

EXPORT TO EXCEL
1. Click "Export" or "Download"  
2. Open the Excel file
3. Verify it includes:
   - Estimate name and details
   - All line items with configurations
   - Cost breakdown (DBU + VM costs)
   - Total monthly cost

Test Checkpoints:
□ Can you save estimates?
□ Can you export to Excel?
□ Is Excel file formatted correctly?
□ Are all details included?


STEP 5: VIEW SAVED ESTIMATES (5 minutes)

1. Navigate to "My Estimates" or "Saved Estimates"
2. Find your previously saved estimate
3. Open the estimate
4. Verify all line items are preserved

Test Checkpoints:
□ Can you see list of saved estimates?
□ Can you open saved estimates?
□ Are all line items preserved correctly?
□ Can you edit saved estimates?


STEP 6: TEST SALESFORCE INTEGRATION (5 minutes)

1. Create a new estimate
2. Tag with Salesforce:
   - Search and select Account
   - Select Opportunity (filtered by account)
   - Select Use Case (filtered by account)
3. Save estimate
4. Return to estimate list
5. Verify tags are visible

Test Checkpoints:
□ Can you search and select Salesforce accounts?
□ Do opportunities filter by selected account?
□ Do use cases filter by selected account?
□ Are tags saved with estimate?
□ Can you filter estimates by Salesforce tags?
