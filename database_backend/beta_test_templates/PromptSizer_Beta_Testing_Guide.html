PromptSizer Beta Testing Guide

What is PromptSizer?
An AI-powered tool that helps you estimate Databricks costs. Simply describe your workload in natural language, and the AI will recommend configurations and calculate costs.

Time Required: 20-30 minutes
What You'll Do: Test 3+ workload scenarios, check AI recommendations, compare costs

Step 1: Access the Tool

App URL: [To be provided by team]

Open the URL in your browser and login if required.

Step 2: Test Basic Scenarios (10-15 minutes)

Test at least 3 different workload types from the list below:

Example Scenarios to Try:

Workload Type Example Description
Data Ingestion "We need to ingest data from Salesforce every hour, processing about 5GB per run"
ETL Jobs "Nightly ETL job processing 500GB of data, takes about 2 hours to run, 6 days a week"
SQL Analytics "50 business analysts running SQL queries 8 hours a day, typical queries take 30 seconds"
ML Training "Train a machine learning model on 1TB dataset weekly, takes 4 hours per training run"
Real-time Streaming "Process Kafka streams 24/7, handling 100K events per second"
Interactive Notebooks "10 data scientists exploring data in notebooks, average 6 hours per day per person"
How to Test:
1. Paste a workload description into PromptSizer
2. Click "Analyze Workload"
3. Review the AI's recommendations (SKU, instance types, costs)
4. Check if it makes sense for the described workload
5. Note any issues or surprises

Step 3: Test Manual Editing (5 minutes)

After AI suggests a configuration, try editing:

  • Change the instance type (e.g., from m5.xlarge to m5.2xlarge)
  • Change number of workers
  • Change run frequency (runs per day)
  • Toggle Photon on/off
  • Switch between Classic and Serverless

Check: Do costs update correctly when you make changes?

Step 4: Test Edge Cases (5 minutes)

Try to break it! Test with:

  • Very vague description: "I need to process data"
  • Very detailed description with specific requirements
  • Unrealistic requirements: "Process 1 billion records per second"
  • Multiple workloads in one prompt

Step 5: Compare with Real Costs (if possible)

If you have experience with actual Databricks costs:

  • Describe a workload similar to one you know
  • Compare PromptSizer's estimate with actual costs
  • Note: ±10% difference is excellent, ±20% is acceptable

What to Record

Please fill in the 4 CSV spreadsheets provided:

1. User Scenarios (1_user_scenarios.csv)

Track which scenarios you tested and whether they worked correctly.

2. Feature Testing (2_feature_testing.csv)

Rate different features (AI understanding, recommendations, cost accuracy, etc.) from 1-5.

3. Issues Found (3_issues_found.csv)

Report any bugs or problems you encounter.

Severity Levels:
• Critical: Can't use the tool at all
• High: Feature doesn't work or gives wrong results
• Medium: Confusing or annoying
• Low: Minor issue or suggestion

4. Overall Feedback (4_overall_feedback.csv)

Your overall impressions and whether you'd use this with customers.

What We're Looking For

🚨 Critical Issues (Report Immediately!)

  • AI gives completely wrong recommendations
  • Costs are wildly incorrect (>50% off)
  • Tool crashes or freezes
  • Can't edit configurations
  • Export doesn't work

💡 High Value Feedback

  • "AI didn't understand this type of workload..."
  • "Costs are off for this scenario..."
  • "I wish it could do..."
  • "This part was confusing..."

✨ Nice to Have

  • UI/UX suggestions
  • Missing workload types
  • Additional features you'd want

FAQ

Question Answer
How accurate should costs be? Within ±10% of actual costs is great. Within ±20% is acceptable for beta.
What if I don't know Databricks costs? That's fine! Just test if AI understands your workload and recommendations seem reasonable.
How long should testing take? 20-30 minutes minimum. More is better!
What if I find bugs? Note them in Sheet 3 (Issues Found). Critical bugs - let team know immediately!
Can I test multiple times? Yes! Try different workload descriptions and see if you get consistent results.
